## crypto-pq

[crypto-pq](https://github.com/crypterial/crypto-pq) is post-quantum cryptography in pure Rust, built to a public specification: ML-KEM, ML-DSA and SLH-DSA (FIPS 203, 204 and 205), FrodoKEM, HSS/LMS and XMSS, with SHA-2, SHA-3, BLAKE2, BLAKE3, Ascon, HMAC and HKDF, in one `no_std` crate with no dependencies.

[Project page](https://crypterial.com/research/crypto-pq/) · [crates.io](https://crates.io/crates/crypto-pq) · [Documentation](https://docs.rs/crypto-pq) · [Specification](https://github.com/crypterial/crypto-pq/tree/main/spec)

## How we work

We contribute fixes and findings back to the projects and standards we depend on, and every design decision is recorded with the code, so the work can be checked rather than taken on trust.

## Security

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/crypterial/crypto-pq/security/advisories/new), never in a public issue. The [security policy](https://github.com/crypterial/.github/blob/main/SECURITY.md) covers every repository.

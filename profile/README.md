<h2 align="center">Crypterial Labs</h2>

<p align="center">A research and engineering lab for cryptography: post-quantum standards, proof systems, privacy-preserving computation, and the places where cryptography meets AI.</p>

We build cryptographic infrastructure for the post-quantum transition and release it as open source. We contribute fixes and findings back to the projects and standards we depend on, and every design decision is recorded with the code, so the work can be checked rather than taken on trust.

Our first project is [crypto-pq](https://github.com/crypterial/crypto-pq), post-quantum cryptography written from scratch in Rust to a public specification, with no external dependencies. It is in development.

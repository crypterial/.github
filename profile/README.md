<h2 align="center">Crypterial Labs</h2>

<p align="center">A research and engineering lab for cryptography: post-quantum standards, proof systems, privacy-preserving computation, and the places where cryptography meets AI.</p>

We build cryptographic infrastructure meant to outlast the systems it protects, and we release it as open source. What we build goes back to the projects and standards it depends on, and every design decision is recorded with the code, so the work can be checked rather than taken on trust.

Our first work is the post-quantum transition: [crypto-pq](https://github.com/crypterial/crypto-pq), post-quantum cryptography written from scratch in Rust to a public specification, with no external dependencies. It is in development.

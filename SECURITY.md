# Security policy

Report vulnerabilities in any Crypterial Labs project privately, never in a public issue.

- Code in this organization: use "Report a vulnerability" (GitHub private vulnerability
  reporting) on the affected repository, or on
  [crypterial/crypto-pq](https://github.com/crypterial/crypto-pq/security/advisories/new)
  if the repository has no security tab.
- The website: see [crypterial.com/.well-known/security.txt](https://crypterial.com/.well-known/security.txt).

You will get an acknowledgement, a fix, and credit in the advisory unless you ask otherwise.
